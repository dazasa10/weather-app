# 🌦️ Buscador del Tiempo (Weather App)

Una aplicación web sencilla y rápida para consultar el clima actual de cualquier ciudad del mundo en tiempo real.

🔗 **Demo en vivo:** [https://dazasa10.github.io/weather-app/](https://dazasa10.github.io/weather-app/)

## 🚀 Tecnologías utilizadas
* **HTML5:** Estructura semántica de la interfaz.
* **CSS3:** Estilos limpios y diseño centrado responsivo.
* **JavaScript (ES6):** Manejo de eventos y llamadas asíncronas con `fetch()`.
* **WeatherAPI:** Consumo de datos meteorológicos en tiempo real.

## ⚙️ Cómo funciona
1. El usuario introduce el nombre de una ciudad en la caja de texto.
2. Al pulsar **Buscar** o la tecla **Enter**, la app realiza una petición a los servidores de WeatherAPI.
3. Se devuelven y renderizan en pantalla los datos de temperatura y el estado del cielo.
